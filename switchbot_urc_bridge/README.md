# SwitchBot URC Bridge

Use your SwitchBot Universal Remote (WoRWS) to turn lights on or off, set a scene, or run a script in Home Assistant. Create a **Bridge remote** in [Remote Studio](https://github.com/batareya16/SwitchbotURCHass) and choose what each button does.

The Bridge runs on **Home Assistant OS** and needs **Mosquitto** plus a **dedicated Bluetooth 5.0+ dongle with connectable LE Extended Advertising**. It automatically makes addresses available for new Bridge remotes and remembers them across restarts.

Open the **Documentation** tab for installation and troubleshooting, or read the [setup guide](DOCS.md) on GitHub. This is an independent community project.
